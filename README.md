# RE｜AI 智能合集 v0.6

基于交接包 v0.5 继续进行 UI 精修，无需安装前端依赖、无需构建。

## 本地预览

在此目录运行：

```bash
python3 -m http.server 4173
```

在本机浏览器访问 `http://localhost:4173`。Chrome 开发者工具切换至移动设备，先设为 **390 × 844**，也可检查 375px 和 430px。桌面浏览时显示手机外壳和简短说明。亦可直接打开 `index.html`，但推荐 HTTP 服务以获得稳定的本地存储行为。

桌面以 **1440 × 900** 验收：左侧为 REDNOTE / UED 概念介绍、四张功能卡片及设计原则；右侧保留 390 × 844 内容区和 8px 外框（外尺寸 406 × 860），手机内部独立纵向滚动。小于 900px 时隐藏介绍，直接显示移动端原型。演示账号为 `momo` / `momo_demo`，头像与其他资料结构沿用模拟素材。

## 本轮调整

- 统一系统字体、SVG 图标、近黑与深灰表面、小圆角及弱分隔。
- 保留个人主页两级收藏导航；原有专辑展示四张方形封面、数量、共享头像及锁图标。
- 「为你整理」只有标题、设置省略号和横滑封面，删除 AI 角标与解释块。
- 合集详情只保留标题、收藏数量和双列笔记流。
- 笔记弹层保留封面、标题、原专辑与纠错；分类依据默认折叠。
- 新建页还原表单分组和权限开关，无底部导航；相似提示为一行建议，不阻止保存。
- 返回首页恢复横滑与纵向位置，弹层隔离背景滚动。

## 演示交互

1. 首页向下滚动进入收藏专辑区域，左右滑动「为你整理」，打开「设计与创作」。
2. 打开一篇笔记，可展开模拟分类依据；选择「不属于这个智能合集」，再点击撤销。
3. 返回原有「视觉设计灵感」专辑，原笔记仍在。
4. 「为你整理」右侧省略号 → 模拟收藏一篇新笔记 → 收藏卧室内容。家居合集增加笔记并前移。
5. 合集内右上省略号可固定或隐藏；首页设置可恢复隐藏项、关闭或开启展示。
6. 创建新专辑，输入「设计灵感」，出现相似提示。可查看，也可直接保存。公开与共享开关由用户控制。

未实现的原生入口只显示范围提示，不连接真实业务服务。

当前云环境已安装 Python Playwright 与 `/usr/bin/chromium`。本地服务运行后执行：

```bash
python3 tests/test_ui.py --base-url http://127.0.0.1:4173
python3 tests/capture_screenshots.py --base-url http://127.0.0.1:4173
```

其他机器需安装 Playwright 与 Chromium，可通过 `--chromium /path/to/chromium` 指定可执行文件。

本轮 10 项测试通过，覆盖 375/390/430px 布局、图片、横纵滚动、位置恢复、纠错撤销、原专辑保护、自动排序与固定、隐藏恢复、相似提示与权限、localStorage、遮罩及 Escape。浏览器控制台和 JavaScript 错误均为 0。未进行真实 iPhone/Safari 测试。

## 数据边界

用户资料为模拟，未接入真实 AI、小红书账号或收费 API。3900/132 为情境数字；实际为 29 条初始笔记、6 个智能合集、8 个原有专辑和 3 条可模拟的新收藏。

沿用 `refold-v05-experience-data` 存储键，兼容已有状态。纠错只改变合集关联，不取消收藏、不移动笔记、不改变原专辑或权限。桌面说明区可恢复初始体验。

`references/` 和 `README_先看这里.md` 为本地交接资料，不提交到公开站点；本版以本文为准。
